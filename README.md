# Benchmark Data for Molass Library

Data sets of **known composition** for testing and demonstrating the Molass Library, kept apart from the tutorial
data of `molass_data` (which stays small).

```
pip install molass_benchmarks
```

```
from molass_benchmarks import PROTEINS5               # contains the folder path
from molass_benchmarks import FOLDUNFOLD_CONTINUUM    # contains the folder path
from molass_benchmarks import FOLDUNFOLD_DISCRETE    # contains the folder path
```

| Attribute | Kind | Content |
|---|---|---|
| `PROTEINS5` | measured | A mixture of five proteins (`20191006_proteins5`); it was `SAMPLE6` of `molass_data` 0.5.0. |
| `FOLDUNFOLD_CONTINUUM` | simulated | A continuum of fold/unfold species: fast-exchange mix of a folded sphere and an unfolded Gaussian chain whose unfolded fraction falls along the elution (Rg from 52 to 26 Å); one peak with a trailing shoulder. |
| `FOLDUNFOLD_DISCRETE` | simulated | Three discrete fold/unfold species with different unfolded fractions (true Rg 52.6, 41.4 and 25.7 Å; Guinier Rg of a quick decomposition 47, 34 and 22 Å): a control that a diagnostic should call discrete. |

The simulated sets are generated by `molass.Testing.simulate_sample4_like("fold_unfold_continuum")` and
`("fold_unfold_discrete")` (molass-library#379; form factors after J. S. Pedersen, Adv. Colloid Interface Sci. 70
(1997) 171) with the photon-counting noise of Sedlak et al. (J. Appl. Cryst. 50 (2017) 621-630; about 30 counts at the
strongest frame and the first q point) on the geometry of a measured data set; the truth is in `ssd.simulation_truth` of the
simulated object and the scripts in `scripts/` regenerate the files.

## Changes

### 0.1.1

- `FOLDUNFOLD_CONTINUUM` and `FOLDUNFOLD_DISCRETE`: the noise is now the published photon-counting model of Sedlak et al.
  (2017) and the stated error is that model's standard error; version 0.1.0 used a stated error and scatter taken from
  a measured data set (no measured error is used any more). Species and geometry are unchanged. The verdicts of
  `get_continuity_report()` are the same (continuum: no evidence, excess 1.84 at k = 3; discrete: `discrete`, excess 3.09).
  `trimmed_copy()` of these sets needs `molass_legacy` with the fix of molass-legacy#104 (otherwise it fails with
  `UnboundLocalError`); for `FOLDUNFOLD_DISCRETE` the default trimming now also cuts frames (220 to 211).
- `PROTEINS5` is unchanged.

### 0.1.0

First version: `PROTEINS5` (moved from `molass_data` 0.5.0, where it was `SAMPLE6`; the files are renamed
`PROTEINS5_*.dat`), `FOLDUNFOLD_CONTINUUM` and `FOLDUNFOLD_DISCRETE`.
